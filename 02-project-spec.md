# Prompt 02 — Project Spec

```md
Com base no inventário e em nova leitura somente quando necessária, gere `01-project-spec.md` no DOSSIER_PATH.

Documente: problema resolvido, usuários/consumidores, escopo e não escopo, capacidades, entradas e saídas, regras de negócio observáveis, interfaces, requisitos operacionais, persistência, segurança, observabilidade, restrições e critérios de saúde. Para cada afirmação importante, cite evidência e marque Confirmado, Inferido ou Não confirmado.

Inclua:
- um flowchart Mermaid do ciclo principal;
- uma tabela de capacidades x evidências;
- cenários felizes, falhas esperadas e casos-limite;
- perguntas que exigem conhecimento humano.

Não transforme hipótese em requisito oficial.
```
